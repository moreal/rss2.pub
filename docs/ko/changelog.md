# 변경 기록

사용자와 운영자에게 영향을 주는 변경을 여기에 기록합니다. 이 페이지는
[영어 원본 변경 기록](/changelog)을 번역한 것입니다.

## [출시 전]

### 추가

- 등록 완료 화면에서 바로 원격 팔로우하며, 계정 이름 복사도 대안으로 제공합니다.
- 등록 완료·계정 페이지에 원본 확인 상태와 마지막 성공·다음 확인 예정 시각을 표시합니다.
- 웹사이트의 복수 피드 후보를 제목·최근 글로 선택합니다. 후보는 최대 8개이며 요청 전체에 45초 시간 예산을 적용합니다.

- AGPLv3 이상 라이선스와 배포된 소스의 링크 설정.
- 자가 호스팅, 릴리스, 데이터베이스 마이그레이션 정책.
- 로컬·컨테이너·Nix 설치를 위한 독립 DB 마이그레이션 명령.
- 리디렉션 대상을 포함한 피드·favicon 요청의 공개 주소 검사.
- 익명 등록의 시도 횟수, 일일 추가 수, 저장된 피드 수, 동시 fetch,
  웹 요청 본문 한도.
- `docs.rss2.pub`에서 제공하는 영어·한국어 문서.

### 변경

- Fedify 관련 의존성을 2.4.1로 올렸습니다. 2.4 마이너 릴리스와 함께
  액터 인증, 외부 배달의 SSRF, 문서 읽기 크기 제한, 대체 문서 링크 탐색의
  보안 수정을 포함합니다. 적용하려면 재배포가 필요하며 애플리케이션 DB
  마이그레이션은 필요하지 않습니다.

- 등록 오류에 원인별 다음 행동과 링크를 안내합니다. 일시적 제한에는 URL 오류 표시 대신 재시도 시간을 안내합니다.
- `0010` 마이그레이션이 피드 확인 시각을 기록하며 과거 이력을 임의로 채우지 않습니다.
- JavaScript가 꺼져 있을 때는 화면 전환 효과를 비활성화해 연속 폼 제출을 사용할 수 있게 합니다.

- RSS 2.0 파서가 핵심 스펙의 채널·아이템 요소(enclosure, author, categories,
  comments, source, content:encoded, cloud, image, textInput, skip 일정,
  타임스탬프, 메타데이터 필드)를 소비합니다. W3C RSS 2.0 conformance 프로필도
  이에 맞춰 재분류했습니다.
- 운영 환경에서 명시적인 공개 `ORIGIN` 설정이 필요합니다.
- 피드·favicon의 실제 소켓 연결에 쓰이는 DNS 주소까지 검사합니다.
  favicon HTML 읽기에는 크기 제한을 적용하고, 리디렉션된 최종 페이지를
  기준으로 아이콘 URL을 해석합니다.
- 컨테이너 공개는 `main`의 모든 push가 아닌 검증된 릴리스 태그에 연결됩니다.
