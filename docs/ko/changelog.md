# 변경 기록

사용자와 운영자에게 영향을 주는 변경을 여기에 기록합니다. 이 페이지는
[영어 원본 변경 기록](/changelog)을 번역한 것입니다.

## [출시 전]

### 추가

- AGPLv3 이상 라이선스와 배포된 소스의 링크 설정.
- 자가 호스팅, 릴리스, 데이터베이스 마이그레이션 정책.
- 로컬·컨테이너·Nix 설치를 위한 독립 DB 마이그레이션 명령.
- 리디렉션 대상을 포함한 피드·favicon 요청의 공개 주소 검사.
- 익명 등록의 시도 횟수, 일일 추가 수, 저장된 피드 수, 동시 fetch,
  웹 요청 본문 한도.
- `docs.rss2.pub`에서 제공하는 영어·한국어 문서.

### 변경

- 운영 환경에서 명시적인 공개 `ORIGIN` 설정이 필요합니다.
- 피드·favicon의 실제 소켓 연결에 쓰이는 DNS 주소까지 검사합니다.
  favicon HTML 읽기에는 크기 제한을 적용하고, 리디렉션된 최종 페이지를
  기준으로 아이콘 URL을 해석합니다.
- 컨테이너 공개는 `main`의 모든 push가 아닌 검증된 릴리스 태그에 연결됩니다.
