# rss2.pub

rss2.pub는 Atom 1.0 또는 RSS 2.0 피드를 페디버스에서 팔로우할 수 있는 계정으로
만듭니다. RSS 1.0은 지원하지 않습니다.

피드를 등록하려면 [rss2.pub](https://rss2.pub/)에서 피드 URL을 제출하세요.
`rss2pub` 계정에 `register <feed-url>`을 멘션해도 됩니다. 서비스가 알려주는
피드 계정 핸들을 자신의 페디버스 서버에서 검색한 뒤 팔로우하면 새 항목을 받을 수
있습니다.

직접 서버를 운영하려면 [자가 호스팅 안내](/ko/self-hosting)를 참고하세요.
업그레이드 전에 [DB 마이그레이션 정책](/ko/database-migrations)과
[변경 기록](/ko/changelog)을 읽으세요. 애플리케이션 소스는
[GNU AGPLv3 이상](https://github.com/moreal/rss2.pub/blob/main/LICENSE)으로 공개됩니다.
