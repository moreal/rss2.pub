# rss2.pub

rss2.pub는 Atom 1.0 또는 RSS 2.0 피드를 페디버스에서 팔로우할 수 있는 계정으로
만듭니다. RSS 1.0은 지원하지 않습니다.

피드를 등록하려면 [rss2.pub](https://rss2.pub/)에서 피드 URL을 제출하세요.
`rss2pub` 계정을 멘션하고 피드 또는 웹사이트 URL을 바로 적어도 됩니다. 서비스가 알려주는
웹사이트에서 읽을 수 있는 피드가 여러 개 발견되면 원하는 피드를 선택합니다.
멘션으로 등록할 때는 후보 URL을 답장받아 원하는 URL로 다시 멘션하면 됩니다.
등록 완료 화면이나 계정 페이지에 자신의 페디버스 계정을 입력하면 자신의 서버로
이동해 팔로우를 확인할 수 있습니다. 피드 계정 핸들을 복사해 앱에서 검색하는
방법도 사용할 수 있습니다.

피드 계정 페이지에는 원본 확인의 대기·정상·실패 상태와 마지막 성공·다음 확인
예정 시각이 표시됩니다. 이 상태는 원본 수집 기준이며, 원격 서버에 게시물이
전달되기까지는 시간이 더 걸릴 수 있습니다.

직접 서버를 운영하려면 [자가 호스팅 안내](/ko/self-hosting)를 참고하세요.
