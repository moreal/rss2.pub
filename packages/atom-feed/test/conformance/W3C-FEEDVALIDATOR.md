# W3C Feed Validator Atom corpus

The conformance suite uses selected Atom fixtures from the
[W3C Feed Validator](https://github.com/w3c/feedvalidator) repository at
commit `9ce274c9db93796b8ab2a44952b9da80811bf765`.

The selected fixture glob is `testcases/atom/[0-9]*/**/*.xml`; it contains
381 files at that commit. The upstream license is preserved unmodified at
`vendor/w3c-feedvalidator/LICENSE`.
